# Экспорт структуры таблиц Snowflake в Excel

## Описание

Скрипт и веб-интерфейс для экспорта полной информации о структуре таблиц Snowflake в Excel файл.

---

## Способы использования

### 1. Через веб-интерфейс (рекомендуется)

1. Войдите в систему как администратор
2. Перейдите в админ-панель (`/admin`)
3. Нажмите кнопку **"Экспорт структуры Snowflake"**
4. Файл автоматически скачается

**Файл будет содержать:**
- Лист "Список таблиц" - сводная информация о всех таблицах
- Отдельный лист для каждой таблицы с полной информацией о колонках

---

### 2. Через командную строку

Запустите скрипт:

```bash
python export_snowflake_schema_to_excel.py
```

Файл будет создан в текущей директории с именем:
`snowflake_schema_YYYYMMDD_HHMMSS.xlsx`

---

## Содержимое Excel файла

### Лист "Список таблиц"

| Колонка | Описание |
|---------|----------|
| Название таблицы | Имя таблицы |
| Тип | Тип таблицы (обычно "BASE TABLE") |
| Количество строк | Количество записей в таблице |
| Количество колонок | Количество колонок в таблице |

### Листы для каждой таблицы

Каждая таблица имеет отдельный лист с:

1. **Заголовок таблицы** - название таблицы
2. **Информация о таблице:**
   - Тип таблицы
   - Количество строк
   - Количество колонок
   - Первичный ключ (если есть)
   - Ограничения (если есть)

3. **Таблица колонок:**
   - Порядковый номер
   - Название колонки
   - Тип данных (с размерами, если применимо)
   - Максимальная длина (для строковых типов)
   - Точность/Масштаб (для числовых типов)
   - NULL разрешен (Да/Нет)
   - Значение по умолчанию
   - Комментарий

---

## Форматирование

- **Заголовки:** Зеленый фон (#1DB954), белый жирный шрифт
- **Границы:** Тонкие границы для всех ячеек
- **Автоподбор ширины:** Колонки автоматически подстраиваются под содержимое
- **Перенос текста:** Включен для длинных значений

---

## Требования

1. **Переменные окружения в `.env`:**
   ```env
   SNOWFLAKE_USER=ваш_пользователь
   SNOWFLAKE_PASSWORD=ваш_пароль
   SNOWFLAKE_ACCOUNT=ваш_аккаунт
   SNOWFLAKE_WAREHOUSE=COMPUTE_WH
   SNOWFLAKE_DATABASE=SPOTIFY_DB
   SNOWFLAKE_SCHEMA=PUBLIC
   ```

2. **Библиотеки:**
   ```bash
   pip install openpyxl snowflake-connector-python python-dotenv
   ```

---

## Обработка ошибок

- Если таблицы не найдены - будет показано сообщение об ошибке
- Если нет подключения к Snowflake - будет показана ошибка подключения
- Если OpenPyXL не установлен - будет предложено установить библиотеку

---

## Примечания

- Экспорт выполняется только для таблиц типа "BASE TABLE"
- Views и другие объекты не экспортируются
- Количество строк может быть не доступно для очень больших таблиц
- Все действия логируются в audit_logs
