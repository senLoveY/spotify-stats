# Скрипт добавления ARTIST_ID и ALBUM_ID в таблицу TRACKS

## Описание

Скрипт `add_artist_id_to_tracks.py` добавляет колонки `ARTIST_ID` и `ALBUM_ID` в таблицу `TRACKS` в Snowflake и заполняет их данными из таблиц `ARTISTS` и `ALBUMS` соответственно, или получает информацию через Spotify API, если данные не найдены в базе данных.

## Требования

1. **Python 3.7+**
2. **Установленные библиотеки:**
   ```bash
   pip install snowflake-connector-python requests python-dotenv
   ```

3. **Переменные окружения в `.env` файле:**
   - `SNOWFLAKE_USER` - пользователь Snowflake
   - `SNOWFLAKE_PASSWORD` - пароль Snowflake
   - `SNOWFLAKE_ACCOUNT` - аккаунт Snowflake
   - `SNOWFLAKE_WAREHOUSE` - warehouse (по умолчанию `COMPUTE_WH`)
   - `SNOWFLAKE_DATABASE` - база данных (по умолчанию `SPOTIFY_DB`)
   - `SNOWFLAKE_SCHEMA` - схема (по умолчанию `PUBLIC`)
   - `SPOTIFY_CLIENT_ID` - Client ID для Spotify API
   - `SPOTIFY_CLIENT_SECRET` - Client Secret для Spotify API

## Использование

### Запуск скрипта:

```bash
python add_artist_id_to_tracks.py
```

или

```bash
./add_artist_id_to_tracks.py
```

## Как работает скрипт

1. **Подключение к Snowflake** - устанавливает соединение с базой данных

2. **Создание таблицы ALBUMS** - создает таблицу `ALBUMS`, если её нет

3. **Добавление колонок ARTIST_ID и ALBUM_ID** - проверяет наличие колонок `ARTIST_ID` и `ALBUM_ID` в таблице `TRACKS` и добавляет их, если отсутствуют

4. **Поиск треков** - получает все треки, у которых отсутствует `ARTIST_ID` или `ALBUM_ID`, но есть имя артиста (`ARTIST`)

5. **Обработка каждого трека:**

   **Для артистов:**
   - **Шаг 1:** Ищет артиста в таблице `ARTISTS` по имени (без учета регистра)
   - **Шаг 2:** Если не найден в базе, получает информацию через Spotify API:
     - Сначала пытается получить через `track_id` (более точно)
     - Затем пытается поиск по имени артиста
   - **Шаг 3:** Если артист найден через API, сохраняет его в таблицу `ARTISTS`
   - **Шаг 4:** Обновляет `ARTIST_ID` в таблице `TRACKS`

   **Для альбомов:**
   - **Шаг 1:** Получает информацию об альбоме через Spotify API по `track_id`
   - **Шаг 2:** Проверяет, есть ли альбом в таблице `ALBUMS` по ID
   - **Шаг 3:** Если альбом не найден в базе, сохраняет его в таблицу `ALBUMS`
   - **Шаг 4:** Обновляет `ALBUM_ID` в таблице `TRACKS`

6. **Статистика** - в конце выводит детальную статистику обработки:
   - Сколько треков обработано
   - **Артисты:** найдено в БД / через API / не найдено
   - **Альбомы:** найдено в БД / через API / не найдено
   - Количество ошибок

## Структура таблиц

### TRACKS
- `TRACK_ID` - ID трека (Spotify ID)
- `NAME` - название трека
- `ARTIST` - имя артиста (строка)
- `ARTIST_ID` - ID артиста (Spotify ID) - **добавляется скриптом**
- `ALBUM_ID` - ID альбома (Spotify ID) - **добавляется скриптом**

### ARTISTS
- `ARTIST_ID` - ID артиста (Spotify ID, PRIMARY KEY)
- `NAME` - имя артиста
- `POPULARITY` - популярность артиста
- `FOLLOWERS` - количество подписчиков
- `GENRES` - массив жанров (ARRAY)
- `IMAGE_URL` - URL изображения артиста

### ALBUMS (создается скриптом, если не существует)
- `ALBUM_ID` - ID альбома (Spotify ID, PRIMARY KEY)
- `NAME` - название альбома
- `ARTIST_ID` - ID артиста (Spotify ID) - связь с таблицей ARTISTS
- `RELEASE_DATE` - дата выпуска альбома
- `TOTAL_TRACKS` - общее количество треков в альбоме
- `ALBUM_TYPE` - тип альбома (album, single, compilation)
- `IMAGE_URL` - URL обложки альбома

## Ограничения и особенности

1. **Лимиты Spotify API** - скрипт делает задержку 0.1 секунды между запросами, чтобы не превысить лимиты API
2. **Обработка ошибок** - скрипт продолжает работу даже при ошибках для отдельных треков
3. **Токен Spotify** - токен получается один раз и используется для всех запросов (действителен 1 час)
4. **Поиск артиста** - при поиске в базе данных используется сравнение без учета регистра (`UPPER(TRIM(NAME))`)

## Примечания

- Скрипт можно запускать несколько раз - он обрабатывает только треки без `ARTIST_ID` или `ALBUM_ID`
- Если артист или альбом уже есть в соответствующих таблицах, скрипт не будет делать лишние запросы к API
- Скрипт создает таблицу `ALBUMS` автоматически, если её нет
- Альбомы получаются через Spotify API по `track_id`, что обеспечивает высокую точность данных
- Скрипт безопасно обрабатывает прерывание (Ctrl+C)
- Для каждого трека выполняется один запрос к Spotify API для получения информации об альбоме (если альбом не найден в базе)
