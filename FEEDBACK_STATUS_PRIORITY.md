# Допустимые значения для Status и Priority в таблице feedback

## Поле: **status** (Статус обратной связи)

**Тип данных:** VARCHAR(20)  
**Значение по умолчанию:** 'new'  
**Обязательное:** Да (NOT NULL)

### Допустимые значения:

| Значение | Описание | Использование |
|----------|----------|---------------|
| `new` | Новый | Статус по умолчанию при создании обратной связи. Обратная связь еще не была рассмотрена администратором |
| `reviewed` | Рассмотрен | Обратная связь была просмотрена администратором, но еще не обрабатывается |
| `in_progress` | В работе | Обратная связь находится в процессе обработки/решения |
| `resolved` | Решено | Проблема решена или запрос выполнен |
| `rejected` | Отклонено | Обратная связь была отклонена администратором (не будет обрабатываться) |

**Визуальное отображение в админ-панели:**
- `new` - зеленый фон (#1DB954)
- `in_progress` - желтый фон (#FFCE56)
- `resolved` - синий фон (#36A2EB)
- `rejected` - красный фон (#e91429)
- `reviewed` - серый фон (#666)

## Поле: **priority** (Приоритет обратной связи)

**Тип данных:** VARCHAR(10)  
**Значение по умолчанию:** NULL (не указан)  
**Обязательное:** Нет (может быть NULL)

### Допустимые значения:

| Значение | Описание | Использование |
|----------|----------|---------------|
| `low` | Низкий | Низкий приоритет, не требует срочного внимания |
| `medium` | Средний | Средний приоритет, обычная важность |
| `high` | Высокий | Высокий приоритет, требует внимания |
| `critical` | Критический | Критический приоритет, требует немедленного внимания |
| `NULL` | Не указан | Приоритет не установлен (по умолчанию) |

**Визуальное отображение в админ-панели:**
- `critical` - красный фон (#e91429)
- `high` - розовый фон (#FF6384)
- `medium` - желтый фон (#FFCE56)
- `low` - синий фон (#36A2EB)
- `NULL` - серый текст (—)

## Дополнительная информация

### Поле: **feedback_type** (Тип обратной связи)

**Тип данных:** VARCHAR(50)  
**Значение по умолчанию:** 'other'  
**Обязательное:** Да (NOT NULL)

### Допустимые значения:

| Значение | Описание |
|----------|----------|
| `bug` | Ошибка в системе |
| `feature_request` | Запрос новой функции |
| `complaint` | Жалоба |
| `praise` | Благодарность |
| `other` | Другое |

## Примеры использования

### Создание обратной связи с указанием статуса и приоритета:

```sql
INSERT INTO feedback (user_id, feedback_type, title, message, status, priority)
VALUES (1, 'bug', 'Ошибка при входе', 'Не могу войти в систему', 'new', 'high');
```

### Обновление статуса и приоритета:

```sql
UPDATE feedback 
SET status = 'in_progress', 
    priority = 'critical',
    updated_at = CURRENT_TIMESTAMP
WHERE id = 1;
```

### Запросы с фильтрацией:

```sql
-- Все критические обратные связи
SELECT * FROM feedback WHERE priority = 'critical';

-- Все новые обратные связи
SELECT * FROM feedback WHERE status = 'new';

-- Обратные связи в работе с высоким приоритетом
SELECT * FROM feedback 
WHERE status = 'in_progress' AND priority = 'high';
```

## Workflow статусов

Типичный жизненный цикл обратной связи:

```
new → reviewed → in_progress → resolved
  ↓                              ↓
rejected                      (завершено)
```

**Примечание:** Статус может быть изменен в любом порядке администратором, но типичный workflow показан выше.
